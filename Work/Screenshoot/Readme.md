## Project Description

The Outpatient Display is a simple program that displays a patient's name, consultation fee, laboratory charge, and total bill.

## Patient Information

#  Name: Mustaf
# Consultation Fee:  $10.0
# Lab Charge: $7.0
# Total Bill:* $17.0

# Formula That I Used:

(Total Bill = Consultation Fee + Lab Charge)

Lab Charge: $7.0
Total Bill: $17.0

# Inpatient Display

# Project Description

The Inpatient Display is a simple program that displays a patient's name, consultation fee, room charge per day, number of days stayed, and total bill.

# Patient Information:

* Name: Ali
* Consult Fee: $20.0
* Room Charge per Day: $3.0
* Number of Days: 50
* Total Bill: $170.0

# Bill Calculation

The total bill is calculated by adding the consultation fee to the total room charges.

# Formula That I Used:

`Total Bill = Consult Fee + (Room Charge per Day × Number of Days)`

# Calculation:

`$20.0 + ($3.0 × 50) = $170.0`

# Output


Inpatient Display
Name: Ali
Consult Fee: $20.0
Room Charge per day: $3.0
Number of Days: 50
Total Bill: $170.0

This project demonstrates basic programming concepts, including variables, arithmetic operations, and displaying output.
